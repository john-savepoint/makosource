# FF7 German String Padding Analysis
# What the 'garbage' bytes actually contain
================================================================================

## Summary

The 'garbage' or 'padding' bytes before German strings are NOT random data.
They contain:

1. **Texture/Model Filenames** (plain ASCII)
   - Character portraits: cloud.tim, barre.tim, tifa.tim, etc.
   - Font textures: usfont_*.tim
   - Battle window textures: btl_win_*.tim
   - Weapon textures: buster.tim

2. **Floating-Point Coordinates** (IEEE 754)
   - UI positioning data
   - Common values: 1.0, -1.0, 7.0, 12.0

3. **Null Padding** (0x00)
   - Right-alignment of strings
   - Memory alignment requirements

## Why This Appears as 'Garbage'

The FF7 decoder interprets plain ASCII using: byte + 0x20
This mangles ASCII into accented characters:
  - 'cloud' (63 6C 6F 75 64) becomes 'ãïñôä'
  - 'tifa'  (74 69 66 61)    becomes 'ôéæá'
