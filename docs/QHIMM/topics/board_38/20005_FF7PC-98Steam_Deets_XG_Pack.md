If you're feeling a bit nostalgic for the old XG MIDIs then I got you covered.  All the original XG MIDIs run through the Yamaha S-YXG50 softsynth which is similar if not almost exactly the same as the softsynth included in the original 1998 Eidos release.  Now all in the ogg file format as well as looped seamlessly.  Some enhancements were done to the MIDIs such as some were edited to loop more like their original PSX counterparts, and One-Winged Angel was edited to have Vocals added back into it.  If you want a more authentic MIDI experience, I included a version that doesn't have vocals as well.

There's three versions that can be downloaded.  An IRO to be used with 7th Heaven, an ogg pack that is set up to be used with FFNx but can be freely used however someone liked, and a version set up to be easily installed on The Reunion.  I've also included two extras with an edited opening FMV (Credit goes to Satsuki for his upscaled original FMV) and three sound effects that was with the rest of the MIDIs.

Here's a playlist someone made of what these sound like through this softsynth: [Link](https://www.youtube.com/watch?v=BpAvX5VEelM&list=PL_BhbJAAueZQYWaFUqPD1nuV_h6Qo6ejS)

And here's my edited vocal version of One-Winged Angel: [Link](https://youtu.be/VADEhdstF9c) (Vocals start at around the 1:00 mark.)
