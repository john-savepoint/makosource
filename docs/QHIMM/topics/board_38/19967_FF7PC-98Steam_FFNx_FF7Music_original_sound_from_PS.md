![](https://www.ff8.fr/pub/images/whitein.png)


Original MIDIs from PS1, a light alternative to Anxious Heart / The mod.

Download

**For FFNx 1.8.x+: [FFNx-FF7Music-v1.5.zip](https://www.ff8.fr/pub/FFNx-FF7Music-v1.5.zip)**
**For FFNx 1.7.x: [FFNx-FF7Music-v1.1.zip](https://www.ff8.fr/download/programs/FFNx-FF7Music-v1.1.zip)** (only 1.2 MB!)

FFNx FF7Music is also available in the [Satsuki Yatoshi Mod (SYW)](https://forums.qhimm.com/index.php?topic=20434.msg283018#msg283018)
And in the catalog for 7th Heaven 2.4+
And for 7th Heaven 2.3.3+: [FFNx-FF7Music-v1.07.iro](https://www.ff8.fr/pub/FFNx-FF7Music-v1.07.iro)

Installation (**FFNx 1.8.x+**)

1. You need to install [FFNx 1.8.x+](https://forums.qhimm.com/index.php?topic=19970.0) first.
2. Copy the psf directory next to ff7\*.exe
3. Open FFNx.toml with a text editor
4. Set use\_external\_music to true (remove the # from the beginning of the line if any)
5. Set external\_music\_path to 'psf' (remove the # from the beginning of the line if any)
6. Set external\_music\_ext to 'minipsf' (remove the # from the beginning of the line if any)
7. Set he\_bios\_path to 'psf/hebios.bin' (remove the # from the beginning of the line if any)
**Optional: to override intro music:**
8. Copy the data/movies/OPENING.ogg file to your movies directory
9. Set ff7\_external\_opening\_music to true (remove the # from the beginning of the line if any)

Installation (**FFNx 1.7.x**)

1. You need to install [FFNx 1.7.x](https://forums.qhimm.com/index.php?topic=19970.0) first.
2. Copy the psf directory next to ff7\*.exe
3. Open FFNx.cfg with a text editor
4. Set use\_external\_music to yes (remove the # from the beginning of the line if any)
5. Set external\_music\_path to psf (remove the # from the beginning of the line if any)
6. Set external\_music\_ext to minipsf (remove the # from the beginning of the line if any)
7. Set winamp\_in\_plugin to psf/in\_psf.dll (remove the # from the beginning of the line if any)

Authors

Packed by [myst6re](https://www.ff8.fr).
FFNx uses the [OpenPSF project](https://github.com/myst6re/openpsf) to play PSF files.
Thanks to [Neil Corlett](https://web.archive.org/web/20131214013404/http://www.neillcorlett.com/) for in\_psf.dll and PSF files.
Thanks to [Christopher Snowhill](https://kode54.net/) for its implementation of foo\_psf.
comical, cintro, mogu, tb and wind PSF files were generated by myst6re using [Makou Reactor 1.8](https://forums.qhimm.com/index.php?topic=9658.0).

Notable improvements (aka changes I made to FFNx)


- On the original PC version, sometimes the game lost the music lock condition. This means that you can hear the music stop and restart later. But not anymore! (Examples: Reno first appearance; after the battle against Rufus; after the movie with nibelheim moutains, when Cloud enters the Reactor).
- A music is now paused before a battle and resumed after to the right time
- A music is now paused before the "good night" music, and resumed after to the right time


I added few missing files to the PSF collection made by Neil Corlett:

- **comical:** unused (and unreleased!) music found in a deleted map of the Honey Bee Inn
- **cintro:** Sephiroth intro only, looped for the heavy atmosphere in Nibelheim Manor
- **mogu:** Moggle victory (yeah!), the introduction of the Highwind theme
- **tb:** Main theme alternative (Cloud and Tifa flashback in the lifestream)
- **wind:** Ambient wind (used by FFNx to replace wind.wav)


Known issues


- Main Theme in lifestream (Cloud subconscious) is desynchronized, rename psf/config.disabled.toml to psf/config.toml to plays the track faster
- Main Theme in lifestream (Cloud subconscious) stops early (fixed with 1.3.2)
- Resuming music after battle can take few seconds sometimes (with FFNx 1.7.x only)


Changelog


- **v1.5:** Fix riku length, and add data/movies/OPENING.ogg to be able to override the intro movie music
- **v1.3.2:** Fix tb.minipsf length, and add psf/config.disabled.toml file to synchronize tb
- **v1.3.1:** Renaming mural.minipsf to mura1.minipsf
- **v1.3:** Dropping support for FFNx 1.7.x (v1.2 will be still available). Updating README for FFNx 1.8.x+.
- **v1.2:** Adding required files for FFNx 1.8.x+.
- **v1.1:** Easier installation. Adding a README in french.
- **v1.0.1:** directory name change (from music/vgmstream to music/psf)
- **v1.0:** initial release


Alternatives


- [Anxious Heart / The mod](https://forums.qhimm.com/index.php?topic=14914.msg209232#msg209232) ([Mirror](https://www.nexusmods.com/finalfantasy7/mods/5)): Original Music (OGG format). The best alternative so far, but you need to download a bigger archive
- [FF7Music](https://www.ff8.fr/pub/FF7Music.zip): Old alternative, by Ficedula, kept for posterity. This archive is already configured correctly for the original game, you need more configuration with the Aali's OpenGL driver, and this is not compatible with FFNx.
- [SXG2Ogg audio mod](https://forums.qhimm.com/index.php?topic=14485.0): MIDI XG Sound using SXG2006LE softsynth
- [Deet's XG Pack](https://forums.qhimm.com/index.php?topic=20005.0): MIDI XG Sound using Yamaha S-YXG50 softsynth
