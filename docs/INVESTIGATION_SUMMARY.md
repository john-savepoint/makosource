## Key Findings

### Your Original Question Answered

**Q:** "How does Japanese overcome the 4-byte allocation problem when 'No' is 4 bytes but 'Nein' (German) needs 5?"

**A:** Japanese doesn't need to "overcome" it because **Japanese Hiragana/Katakana use single-byte encoding** in the same index pool as English ASCII:

```
English "No" = 0x4E 0x6F 0xFF 0x00 (4 bytes)
Japanese "いいえ" = 0x6D 0x6D 0x6F 0xFF (4 bytes, SAME LENGTH!)
German "Nein" = 0x4E 0x65 0x69 0x6E 0xFF (5 bytes, LONGER!)
```

The "trick" is that byte 0x6D means:
- 'm' when using `usfont.png` (English font)
- 'い' when using `jafont_1.png` (Japanese font)

**Same byte index, different texture → no extra bytes needed.**

## The FA-FE Multi-Page System

### How It Works

**Page Markers:** 0xFA-0xFE are special bytes that tell the renderer "switch font texture":

```
Text: "魔法" (magic in Kanji)
Bytes: 0xFA 0x1A 0xFA 0x2B 0xFF

Parser reads:
- 0xFA → "Switch to jafont_2.png"
- 0x1A → "Render character at index 26" = 魔
- 0xFA → "Switch to jafont_2.png again"
- 0x2B → "Render character at index 43" = 法
- 0xFF → Terminator
```

**Total Characters Supported:**
- Page 0 (default): 256 characters (Hiragana/Katakana/ASCII)
- Pages 1-5 (0xFA-0xFE): 5 × 256 = 1,280 characters (Kanji)
- **Total: 1,536 character slots** (enough for full JIS Level 1 & 2)

### Why German Doesn't Need This

German only needs ~110 unique characters:
- a-z, A-Z (52)
- ä, ö, ü, Ä, Ö, Ü, ß (7)
- Numbers, punctuation (50)

**All fit in single 256-character texture → No FA-FE markers needed.**

## Critical Technical Details

### Memory Safety

1. **MUST use 0xFF terminators**, not 0x00 (FF7 game requirement)
2. **MUST NOT exceed 32 bytes** for menu strings (corrupts Level field)
3. **MUST pad unused bytes** with 0xFF (not 0x00)

### Character Encoding

- English/German: Single-byte ASCII/Latin-1
- Japanese Hiragana: Single-byte (0x00-0xFF)
- Japanese Kanji: Two-byte sequences (0xFA-0xFE + index)

### Font Textures

- Format: 1024×1024 PNG
- Grid: 16×16 cells = 256 characters
- Cell size: 64×64 pixels per character
- Japanese: 6 textures (jafont_1.png through jafont_6.png)
- German: 1 texture (can reuse modified usfont.png)
