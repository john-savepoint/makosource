# HEXT FORMAT EXPLANATION
# ============================================================================
#
# Each patch has the format:
#   XXXXXX = AA BB CC DD ...
#
# Where:
#   XXXXXX = Virtual Address (VA) in the loaded executable
#   AA BB CC DD = Bytes to write at that address
#
# VA Calculation:
#   VA = (EN_FileOffset - 0x3B8A00) + 0x3BA000 + 0x400000
#
# Example for EN offset 0x518370:
#   VA = (0x518370 - 0x3B8A00) + 0x3BA000 + 0x400000
#      = 0x15F970 + 0x3BA000 + 0x400000
#      = 0x919970
#
# ============================================================================
# BYTE ENCODING REFERENCE
# ============================================================================
#
# FF7 Encoding (DEF type):
#   0x00 = Space
#   0x01-0x5F = ASCII - 0x20 (e.g., 0x21 = 'A', 0x22 = 'B')
#   0xFF = String terminator
#   0xFA-0xFE = Multi-byte prefix for extended characters
#
# Japanese Characters (jafont_1):
#   Hiragana: Various positions (e.g., あ=0x6B, い=0x6D)
#   Katakana: Various positions (e.g., ア=0x6A, イ=0x6C)
#   Fullwidth Latin: Positions 180-205 (Ａ-Ｚ)
