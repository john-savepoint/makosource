SECTION 4: How to Recognize Encoded German Strings
================================================================================

When looking at hex dumps or binary data, German FF7 strings are recognizable by:

1. Pure ASCII text (readable characters): Zauber, Limit, Sound, Konfig
   → These don't need decoding, already human-readable

2. Mixed ASCII + Special Bytes (ä, ö, ü, ß):
   → Look for bytes: E4, F6, FC, DF
   → When you see FC: it's the letter ü
   → When you see E4: it's the letter ä
   → When you see F6: it's the letter ö
   → When you see DF: it's the letter ß

3. String Pattern:
   → Starts at known offset (e.g., 0x00590C68)
   → Contains printable ASCII + possible special bytes
   → Ends with 0x00 (null terminator)

SECTION 8: Why Chunk 86 Looks Corrupted
================================================================================

The strange strings you see in chunk 86 (offset range 0x5D7901-0x5D7E36):

Example: "lD4", "dD,", "$rÖ", "Sõ"/", "ãD,"

These are NOT corrupted data. They are COMPILED CODE.

When you force binary machine instructions to display as text:
  - 0x6C 0x44 0x38 0x28 (CPU instruction) → displays as "lD8("
  - 0x64 0x44 0x2C (CPU instruction)       → displays as "dD,"
  - 0x24 0x72 0xD6 (CPU instruction)       → displays as "$rÖ"

These are x86-64 assembly instructions, not text data.

Status: Ignore these completely - they are not menu strings.

SECTION 9: How to Use This Information
================================================================================

When creating tools or scripts:

1. Reading German strings from executable:
   → Look for byte sequences ending in 0x00 (null terminator)
   → Decode bytes 0x00-0x7F as ASCII
   → Decode bytes 0x80-0xFF using Windows-1252 mapping
   → Stop at 0x00 (end of string)

2. Writing German strings to executable:
   → Convert German text to Windows-1252 bytes
   → Special characters: ä→E4, ö→F6, ü→FC, ß→DF
   → Add 0x00 null terminator
   → Write to correct offset in binary

3. Identifying German text in binary:
   → Readable ASCII characters (normal)
   → Contains bytes: E4, F6, FC, or DF (German umlauts)
   → Ends with 0x00 (null terminator)
   → All present = likely German text
