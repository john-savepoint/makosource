ENCODING KEY:
─────────────────────────────────────────────────────────────────────────────────
FF7 Encoding: ASCII - 0x20
  Example: 'O' = ASCII 0x4F → FF7 0x2F (0x4F - 0x20)

Special Characters:
  0x6A = ä (a-umlaut)    0x7A = ö (o-umlaut)
  0x7F = ü (u-umlaut)    0x7E = ß (eszett)
  0x00 = Space           0xFF = String terminator

Virtual Address: VA = FileOffset + 0x400800
