================================================================================
IMPORTANT NOTES
================================================================================

1. The delta is NOT constant because German text often has different lengths:
   - "BATTLE SPEED" (12 chars) -> "KAMPFTEMPO" (10 chars) = SHORTER
   - "WINDOW COLOR" (12 chars) -> "FENSTERFARBE" (12 chars) = SAME
   - "FIELD MESSAGE" (13 chars) -> "FELDMELDUNG" (11 chars) = SHORTER

2. Even when German is shorter, previous longer strings shift everything.

3. The eStore exes (EN and DE) are from the same source release (Sept 2013),
   which is why they have the same base structure. The Steam exe (Dec 2025)
   has been updated and has a smaller size.

4. For accurate German text extraction, each string should ideally be searched
   independently rather than relying on a constant delta.

5. HIGH confidence mappings (139 entries) are strings identical in both
   languages that were found via exact byte matching.
